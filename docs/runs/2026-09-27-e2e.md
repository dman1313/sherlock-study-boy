## Issues found

1. **Real quizzes are not single-answer multiple choice.** `bank import` failed with `question 2 must have exactly one correct option, found 3`. The downloaded quiz held 12 questions (for `--count 8`) of four types: 4 `multiple_choice`, 3 `multiple_select`, 2 `fill_in_the_blank`, 3 `short_answer`; one question referenced a diagram through `imageUrls`. `nlm` 0.9.14's source only formats `question`, `answerOptions`, and `hint`, which is why the fixtures assumed a narrower shape. Fixed in `fix(sherlock): mark all NotebookLM quiz question types found in the live run`: multiple-select and fill-in are marked automatically, short answers are stored for a future judge, diagram and malformed questions are skipped one at a time, and a failed import that has an artifact can be re-imported without a new generation. The same download then imported cleanly.
2. **First status is `unknown`, not `in_progress`.** Both `nlm quiz create` calls returned `"status": "unknown"`; both quizzes completed within about two minutes. The polling rule (keep polling while `unknown`, up to 10 minutes) handled this correctly. Documented in `references/nlm-cli-quirks.md`.
3. **`nlm` reported an update (0.12.0).** Not applied, because this run validates 0.9.14. Upgrading should get its own live run.
